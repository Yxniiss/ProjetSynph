# Symfony User Authentication App

This project is a web application built with Symfony.

The goal of this project is to practice backend development and user authentication features.

## Features

- User registration
- User login
- User authentication system
- Basic website pages
- Contact form

## Technologies

- PHP
- Symfony
- Twig
- Doctrine
- HTML
- CSS
- JavaScript

## Purpose

This project was created to learn how to build a web application with Symfony and understand how authentication systems work.

⚠️ This project is mainly a learning project and may not be fully optimized.

## Installation

1. Clone the repository

2. Install dependencies

3. Run the project
